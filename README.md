### About

Third-year Electronics & Communication Engineering (AI-ML) student. I come at security from the
hardware side — reading a datasheet, soldering a test point, and following a signal from a pin
into the firmware behind it. I lead **Hack-X**, my campus security club (CTFs, workshops), and
placed **2nd runner-up at HackMITWPU'25** with team PARAM.

Right now I'm building a portfolio of firmware and hardware-interface security work — attack,
evidence, and fix — one project and writeup at a time.

### What I work with

- **Languages:** C, Python, Bash
- **Hardware:** ESP32, ESP8266, Raspberry Pi 5, Arduino, NRF24L01, LoRa (SX1278)
- **Interfaces:** UART · SPI · I²C · GPIO
- **Security:** Linux, Wireshark, Nmap, Burp Suite, OWASP Top 10, CTFs
- **Learning now:** firmware extraction & static analysis (Binwalk, Ghidra), secure boot, logic-analyzer work
